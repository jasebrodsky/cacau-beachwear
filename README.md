# CACAU Beachwear

A visual brand concept site for CACAU, a proposed Brazilian beachwear label inspired by Rio de Janeiro.

This is a presentation, not a store. There is no cart, checkout, or inventory.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Photography is sourced from Pexels and self-hosted. Credits appear in the site footer.
